# ⚡ AcxiomCRM — Enterprise Sales Suite

AcxiomCRM is a full-stack Customer Relationship Management (CRM) application designed to manage customers, leads, sales opportunities, follow-ups, and customer activities in one place.


## ✨ Features

- Customer management and search
- Lead tracking and conversion
- Sales opportunity management
- Follow-up scheduling
- Customer activity tracking
- Reports and CSV export
- Authentication and role-based access control

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Build Tools:** Maven, npm

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/SoumitriRoy05/Acxiom_CRM_Project.git
cd Acxiom_CRM_Project
```

**2. Start the backend**

```bash
cd backend
mvn spring-boot:run
```

**3. Start the frontend** in a separate terminal.

```bash
cd frontend
npm install
npm run dev
```

Configure your MySQL database and backend credentials before running the application.
